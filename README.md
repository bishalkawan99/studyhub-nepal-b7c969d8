Final Goal

Build a premium-quality educational platform similar to top learning websites, designed specifically for Nepalese Class 11 and Class 12 students. The website should feel modern, trustworthy, visually appealing, easy to navigate, and optimized for speed and SEO. The admin panel must allow secure email/password login and make it simple to upload, edit, organize, and publish notes, exercise answers, question banks, MCQs, model questions, and past papers without requiring code changes.
